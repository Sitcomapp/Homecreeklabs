# Home Creek Labs

The website for Home Creek Labs, Inc., served at https://homecreeklabs.app.

It's a plain static site with no build step: `index.html` plus the `img/` folder.

- **Add an app:** copy an `<article class="feature">` block in `index.html` and change its name, copy, screenshot and store links.
- **Update the numbers:** edit the `METRICS` object near the bottom of `index.html`. Use `null` for anything not measured yet.
- **Store links:** replace the `href="#"` on the App Store and Google Play buttons.
